13. Semantic HTML

Semantic elements clearly describe their purpose.

  • <header> - introductory content
  • <nav> - navigation links
  • <main> - main page content
  • <section> - thematic section
  • <article> - independent content
  • <aside> - related/sidebar content
  • <footer> - footer information

What is an Article?

An article represents independent content such as a blog post, news story, or forum post.

Tip: Use semantic HTML because it improves accessibility and makes the structure easier to understand.
